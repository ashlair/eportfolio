Project Overview

World Cities

ASP.NET Core Web API & Angular

A full-stack web application for browsing, searching, and managing a database of world cities and countries. A C# ASP.NET Core Web API backed by SQL Server serves paged, sorted, and filtered data to an Angular Material front end.

Overview

World Cities is split into two projects in one Visual Studio solution: WorldCitiesAPI, an ASP.NET Core 6 Web API that owns the data and business rules, and WorldCities, an Angular 13 single-page application that consumes it. The database is seeded from a spreadsheet of real-world city data, then exposed through REST endpoints that support server-side paging, sorting, and filtering so the UI stays fast even with large tables.

I built it by following ASP.NET Core 6 and Angular (Valerio De Sanctis, Packt) to practice the full request path end to end: relational modelling with Entity Framework Core, a clean API contract, and a reactive Angular front end with validated forms.
